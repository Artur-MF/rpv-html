CSS GRID

O Arquiteto da Estrutura Bidimensional

Perfeito para layouts complexos de páginas inteiras, controlando linhas e colunas simultaneamente.

Poder do Flex: Alinhamento Fluido

Flexbox trata os elementos como um fluxo elástico. No exemplo abaixo, usamos justify-content: space-between e align-items: center.

1
2
3

display: flex; justify-content: space-between; align-items: center;

Domínio do Grid: Estrutura Total

Grid permite definir "áreas" no layout. O exemplo abaixo cria um layout clássico de dashboard com apenas algumas linhas de CSS.

Header (Span total)
Sidebar
Conteúdo Principal (Área Expandida)
Footer

display: grid; grid-template-areas: "header..." "sidebar main..." "footer...";
